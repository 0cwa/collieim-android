## Important update notice

This is the final Stable release with duplicate APK filenames. We’re keeping `collie-foss.apk`, `molly-continued.apk`, `molly-foss-continued.apk`, and `molly-minimal.apk` for one more release so the new in-app notice can warn you before they go away. Starting with the next Stable release, only `collie.apk` will ship. You can update your existing installation in place.

**Using an older Obtainium configuration?** Change the APK filter to `^collie\.apk$` or use the [current Collie setup](https://collie.im/obtainium/). You can also use Settings → Collie → App updates or update through F-Droid.

## What’s new

- **Setup and delivery status.** See your status under Collie. The Finish Setup checklist shows what still needs attention, and a banner alerts you to delivery problems. Read What’s New for release highlights and notices.
- **Project log.** Browse bundled release history offline in Settings → Help → Project log or from What’s New.
- **App updates.** Find App updates at the top of Settings → Collie. The version shortcut is still in Help.
- **Hardening.** In Settings → Collie → Hardening, you can require your current PIN before changing recovery PIN settings and require phone authentication before viewing, exporting, or rotating your backup recovery key. Both controls are opt-in.
- **UnifiedPush.** The settings are simpler, pairing takes one QR scan, and you can export enrollment manually through Android’s file picker. Linked devices support encrypted push, and existing relays keep working without reconfiguration.
- **Backups and transfers.** Collie preserves backup alias indexes and rollback state, verifies which account is importing, and reports failed transfers correctly. Attachment key backfill and archive retries stay tied to the selected file, and Collie discards stale upload snapshots. UnifiedPush refreshes when a key rotates at the same URL.
- **TrailBlazer Beta.** Group Privacy (group admission controls) and local attachment-only removal remain in TrailBlazer Beta `8.36.3-3-beta1` for real-world testing.
- Based on Signal 8.36.3.
