# Collie

<p align="center">
  <img src="assets/collie-foreground.svg" alt="Collie icon" width="180">
</p>

Collie is an independent Android messenger built on [Signal](https://signal.org/) and [Molly](https://molly.im/). It brings their private messaging features together with more choice over what stays on your device.

Collie uses the Signal network, so you can talk to your Signal contacts. Its optional retention controls let you keep disappearing messages and view-once media, ignore remote deletion requests, or delete media without deleting messages. These controls are off by default.

## One project, five variants

All five variants are maintained from the same codebase.

| Variant | What it offers |
| --- | --- |
| **Molly Minimal** | Molly's core features, updated to a newer Signal base. |
| **Molly Continued** | Molly Minimal with additional fixes and improvements. |
| **Molly FOSS Continued** | Molly Continued without Firebase. |
| **Collie** | Molly Continued with extra message and media retention controls, as a separate app. |
| **Collie FOSS** | Collie without Firebase. |

The Molly variants keep Molly's app identity so they can replace an existing Molly installation. Collie and Collie FOSS have their own app identity and can be installed separately.

The variants are in development; this table describes the intended releases, not current download availability.

## Origins

Collie builds on the work of the [Signal](https://github.com/signalapp/Signal-Android), [Molly](https://github.com/mollyim/mollyim-android), and [Signal FOSS](https://github.com/tw-hx/Signal-Android) contributors. It is not an official release of any of those projects.
