## Important update notice

This is the final Stable release with duplicate APK filenames, including `collie-foss.apk` and `molly-*.apk`. Starting with the next Stable release, use `collie.apk`. You can update your existing installation in place.

If you use Obtainium, change your APK filter to `^collie\.apk$`. You can also use Settings → Collie → App updates or update through F-Droid.

## What’s new

- The Setup checklist and push health tools show what needs attention.
- App updates is now near the top of Settings → Collie. Help → Project log shows the current build and Stable release history.
- Hardening controls let you require phone authentication for backup recovery key access and the current PIN for recovery PIN changes.
- UnifiedPush setup is simpler. Pair with one QR scan and receive push on linked devices.
- Based on Signal 8.36.3.
