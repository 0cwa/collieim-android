# Maintaining Collie's upstream fork

Follow the [upstream upgrade workflow](https://github.com/0cwa/collie-release-engineering/blob/main/docs/DEVELOPMENT-CYCLE.md) when bringing in an upstream release.

Before integrating a release, check for donation navigation, manifest activities, setup and renewal scheduling, gateway clients, and profile prompts. Collie does not include Signal donation checkout. Reapply its removal to newly introduced donation-only code while preserving backup subscriptions, existing stored records, gift redemption, and separate external support links.

Keep upstream copyright, license, and attribution notices with derived code. Record the specific changes and review evidence in the pull request description.
